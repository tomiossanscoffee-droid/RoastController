■ これは何？
------------------------------------------------------------------------
家庭用スマート焙煎機向けに、焙煎プロファイルを設計・編集・送信し、焙煎を
記録するための「非公式」ツールです。ABC 理論に基づく自動生成、味の傾向の
レーダー表示、実機との BLE 通信、スマホへのプッシュ通知などに対応します。
Web アプリ（ローカル起動）として動作し、macOS ネイティブアプリとしても
使えます。

※ 本ソフトは Panasonic 社・IKAWA 社その他メーカーとは一切無関係の
  個人開発ツールです。無保証・自己責任でご利用ください。
※ メーカー由来のデータ（プリセット等）は含まれていません（後述）。


■ できること
------------------------------------------------------------------------
【同梱データだけで、すぐ使える】
 ・焙煎プロファイルの自動生成（焙煎度・味の3軸調整・産地/標高など）
 ・サンプル保存プロファイル4種（浅/中/中深/深）を初回起動時に用意
 ・プロファイルの手動編集（制御点ドラッグ、フェーズ時間調整、Undo/Redo）
 ・期待される味のレーダー表示・ヘルスチェック
 ・焙煎機との BLE 通信（送信・温度受信・ログ記録）
 ・スマホへのプッシュ通知（HTTPS 起動時。画面ロック中でも届く）

【利用者自身がデータを用意すると使える（任意）】
 ・プリセット/豆情報 … 純正アプリの iPhone バックアップから各自で抽出
 ・IKAWA タブ … IKAWA 公式サイトから各自で取得
 ※ データが無い場合、該当タブは自動的に非表示になります。


■ インストール
------------------------------------------------------------------------
必要なもの:
 ・Python 3（無い場合は起動スクリプト実行時に案内が出ます）
 ・（任意）スマホ通知を使う場合: Tailscale アカウント（無料）
   https://tailscale.com/
 ・（任意）グラフ/フォントを CDN から読み込むためインターネット接続

手順:
 1. GitHub の「Code」→「Download ZIP」で取得して展開（または git clone）。

 2. 起動用ファイルを実行（下記から1つ）。初回は仮想環境の作成と
    パッケージ導入が自動で行われます（数分）。2回目以降はすぐ起動します。

      Mac（通常版）      : start_app.command
      Mac（通知対応版）  : start_app_https.command   ※要 Tailscale
      Windows（通常版）  : start_app.bat
      Windows（通知対応版）: start_app_https.bat      ※要 Tailscale

    ・Mac で「開発元が未確認」と出たら、右クリック →「開く」を選択。
    ・Mac で「適した Python が見つかりません」と出て python.org が
      開いたら、「macOS 64-bit universal2 installer」を入れて再実行。

 3. ブラウザが自動で開き、アプリ画面が表示されます。同じ Wi-Fi 内
    （通知対応版なら Tailscale 経由でどこからでも）スマホ等からも
    アクセスできます。画面右上「モバイル版」から QR コードを表示できます。


■ プリセット・豆情報を使いたい場合（任意・各自で抽出）
------------------------------------------------------------------------
nhm.sqlite が無い場合、プリセット欄は非表示になりますが他機能は使えます。
あなた自身の iPhone のローカルバックアップ（暗号化オフ）から抽出できます。
抽出したデータは再配布しないでください。

  Mac:
    venv/bin/python3 scripts/extract_from_ios_backup.py --dry-run
    venv/bin/python3 scripts/extract_from_ios_backup.py
  Windows:
    venv\Scripts\python.exe scripts\extract_from_ios_backup.py --dry-run
    venv\Scripts\python.exe scripts\extract_from_ios_backup.py

  （まず --dry-run で件数確認 → 問題なければ外して実行）


■ IKAWA プロファイルを使いたい場合（任意・公式サイトから取得）
------------------------------------------------------------------------
ikawa_profiles.json が無い場合、IKAWA タブは非表示になります。

  Mac:
    venv/bin/python3 scripts/extract_ikawa_profiles.py --dry-run
    venv/bin/python3 scripts/extract_ikawa_profiles.py
  Windows:
    venv\Scripts\python.exe scripts\extract_ikawa_profiles.py --dry-run
    venv\Scripts\python.exe scripts\extract_ikawa_profiles.py


■ macOS ネイティブアプリとして使う（任意・上級者向け）
------------------------------------------------------------------------
 1. Xcode Command Line Tools: xcode-select --install
 2. cd macapp && ./run.sh
正式な配布署名は行っていないため、初回はセキュリティ警告が出ることが
あります。「システム設定 → プライバシーとセキュリティ」で
「このまま開く」を選んでください。


■ 困ったときは
------------------------------------------------------------------------
 ・「ポートが使用中」エラー: 一度パソコンを再起動してみてください。
 ・通知がうまく届かない場合は HTTPS 起動版（Tailscale 経由）をお試しを。
